# Street Spot

Street Spot - веб-сервис для поиска и бронирования баскетбольных площадок. Пользователь может искать площадки по названию и адресу, фильтровать по покрытию и освещению, сортировать по рейтингу, смотреть детальную страницу площадки, добавлять новые площадки и удалять их из каталога.

## Технологии

* HTML5, CSS3 (Grid, Flexbox, адаптивная вёрстка).
* JavaScript (Fetch API, `URLSearchParams`, делегирование событий).
* Node.js + Express 5 — раздача статики и REST API.
* Данные сервера хранятся в памяти на основе `app/data/courts.json`.

## Требования

* Node.js 18 или новее.
* npm.

## Установка и запуск

```bash
cd app
npm install
npm run dev
```

Сервер запускается на `http://localhost:3000` (порт можно изменить переменной окружения `PORT`).

```bash
PORT=4000 npm run dev
```

Откройте в браузере `http://localhost:3000`. Запускать сайт нужно именно через сервер, а не открывать HTML-файлы напрямую (`file://`), иначе клиент не сможет обратиться к `/api`.

Для запуска без режима отслеживания изменений:

```bash
npm start
```

## Возможности клиента

* Каталог площадок загружается с сервера через `GET /api/courts`.
* Поиск, фильтрация по покрытию, сортировка и счетчик результатов работают без перезагрузки страницы.
* Главная страница показывает топ-3 площадки по рейтингу и статистику по данным сервера.
* Страница `court.html?id=<id>` загружает конкретную площадку через `GET /api/courts/:id` и показывает сообщение при `404`.
* Форма `add-court.html` отправляет `POST /api/courts`, блокирует кнопку на время запроса и выводит серверные ошибки валидации рядом с полями.
* Форма `add-court.html?id=<id>` загружает площадку и сохраняет изменения через `PATCH /api/courts/:id`.
* В каталоге доступны редактирование и удаление площадки (`DELETE /api/courts/:id`) с подтверждением действия.

## REST API

| Метод | URL | Назначение |
| --- | --- | --- |
| `GET` | `/api/health` | Проверка состояния сервера |
| `GET` | `/api/courts` | Список площадок (query: `surface`, `search`, `sort`) |
| `GET` | `/api/courts/:id` | Одна площадка по идентификатору |
| `POST` | `/api/courts` | Создание площадки |
| `PATCH` | `/api/courts/:id` | Частичное обновление площадки |
| `DELETE` | `/api/courts/:id` | Удаление площадки |
