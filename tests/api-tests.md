# Протокол тестирования REST API Street Spot

Сервер: `http://localhost:3000` (запуск `cd app && npm run dev`).

Тестирование выполнялось через `curl`; аналогичные запросы можно повторить в Thunder Client / Postman.

## Проверенные сценарии

* **Штатные запросы:** получение списка, фильтрация по покрытию, поиск, сортировка, получение по `id`, создание, обновление, удаление.
* **Невалидные данные и параметры:** отсутствие `name`, неверный тип `lighting`, недопустимое покрытие `wood`, рейтинг вне диапазона, нечисловой `id`, битый JSON.
* **Несуществующие идентификаторы:** `GET`/`PATCH`/`DELETE` для `id = 999` возвращают `404`.
* **Служебные маршруты:** неизвестный `/api/*` → JSON `404`, тестовый `/api/debug/error` → `500`, неизвестная страница → `404.html`.

## Примечания

* Данные на сервере хранятся в памяти: после перезапуска сервера созданные и изменённые площадки сбрасываются к исходному массиву `app/data/courts.json`.
* `DELETE` успешно возвращает `204 No Content` с пустым телом — клиентский `requestJson` корректно обрабатывает этот случай.
